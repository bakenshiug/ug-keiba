## 🔍 「変」シグナルの定義

一変激走神宮では、以下を**機械的に検出**します。

### Layer 1: 公式申告の「変」（構造化データ）

ブリンカーは**事前申告が義務**。これは公式情報として確定。

| 項目 | 意味 |
|---|---|
| **初B（初ブリンカー）** | 穴の最大温床 |
| **再B（再ブリンカー）** | 一度外した後の再装着＝試行錯誤 |
| **B外（ブリンカー外し）** | 矯正卒業 or 別アプローチ |
| **B（継続ブリンカー）** | **継続は「変」ではない**（哲学） |

### Layer 2: 申告不要装具の「変」（短評テキスト）

チークピーシーズ・ホライゾネット・シャドーロール・メンコ等は**事前申告不要**。  
そのため**競馬新聞のレース短評**から「装着」言及をキーワード抽出する。

| 項目 | 例 |
|---|---|
| チークピーシーズ | 「チーク着用」「目先替」 |
| ホライゾネット | 「ホラ装着」「視界遮断」 |
| シャドーロール | 「シャドー新装」 |
| メンコ | 「メンコ着用」 |

### Layer 3: 条件「変」

距離延長や距離短縮／芝ダート変／クラス変など、レース条件側の「変」も短評からキーワード抽出。

| カテゴリ | 例 |
|---|---|
| 装具変 | 遮眼革／ブリンカ／目先替 |
| 距離変 | 距離詰／距離延 |
| サーフェス変 | 芝ダ替／ダ芝替 |
| 脚質変 | 気合入／粘り込み注意 |
| 一変系 | 一変／化けた／変身／別馬 |
| クラス変 | 自己条件戻／降級 |

### Layer 4: 合議ボーナス

**公式申告（Layer 1）× 短評記述（Layer 2/3）** が両方揃った時、  
書類仕事と現場の眼が一致した「**陣営の本気度**」が立ち上がる。  
合議ボーナスで確度爆上がり。
